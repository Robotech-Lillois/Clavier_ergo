# Projet Clavier ergonomique

L'objectif du projet et de faire un clavier ergonomique.

Un clavier ergoomique est un clavier qui permet de minimiser la fatigue musculaire, et augmenter la vitesse de frappe.

## Documentation

### Sites Web

- [keyboard design](https://keyboard-design.com) : ensemble de liens utiles pour créer son clavier
- [Un layout intéressant : Vckb2](https://keyboard-design.com/letterlayout.html?layout=vckb2.en.ergodox)
- [Kicad ergodox_ez](https://adamws.github.io/keyboard-pcbs/output/ergodox_ez/ergodox_ez.zip)


## Cahier des charges clavier ergonomique

- port USB
- des switchs enlevables
- une pcb
- un micro processeur

### améliorations

- rgb
- bluetooth
- touches de fonction
    - molette pour modifier le son / la luminosité des leds
